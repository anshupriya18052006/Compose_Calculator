# Compose Calculator

A simple Android Calculator app built using Kotlin and Jetpack Compose in Android Studio.

## Features

- Perform basic arithmetic operations.
- Addition, subtraction, multiplication, and division.
- Interactive calculator buttons.
- Simple and clean user interface.
- Responsive UI using Jetpack Compose.

## Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **IDE:** Android Studio
- **Build System:** Gradle (Kotlin DSL)

## Getting Started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/anshupriya18052006/Compose_Calculator.git
   ```

2. Open the project in Android Studio and let Gradle sync finish.

3. Run the app on an emulator or a physical Android device.
